# output/groundtruth 说明（早期轨迹，非 4.3.7 训练集）

本目录为 2026-08 早期采集的逐次执行轨迹（58 条，`real_execution_*.json`），字段结构与 `data/groundtruth/` 一致：场景名、API 版本、设备序列号、`total_nodes`、总耗时、`evidence`（原子执行记录）。

用途与限制：

1. **不能用于复算 4.3.7 的分类指标。** 论文 4.3.7 使用 1185 条样本（600 正常、175 勒索、585 恶意），本目录条数不足且缺少恶意样本的原子级标签，直接跑 `recalc_downstream_grouped.py` 只会得到“0 原子”并在索引处报错。
2. 与 `data/groundtruth/`（85 条）是两批不同时期的采集，**未合并**：`data/` 侧保留更早的设备记录，本目录为其中较晚的一批。两者都只作为“轨迹格式示例”随仓库发布。
3. 表7 的模拟器侧数字涉及同一批会话，但真机侧因含设备序列号未发布，见 `docs/PAPER_DATA_MAP.md`。
