# output 目录说明

本目录保存论文引用的实验产出，**随仓库发布**，请勿删除或改写：

- `paper/`：论文所用批次数据（表4、图3、表5、表6、表8、4.3.9 的原始记录），子目录内的 `files.txt` 与 `SHA256SUMS` 为逐文件校验清单（部分批次另附 `manifest.json` 采集元信息）；
- `jitter_w6/`：表3 的 W=6 抖动分量测量结果；
- `groundtruth/`：早期逐次执行轨迹（表7 模拟器侧相关）。

重新运行实验时请使用新的输出目录（如 `--out output/runs_local`），不要覆盖既有批次——论文数字与这些批次一一对应，覆盖即失去可追溯性。
